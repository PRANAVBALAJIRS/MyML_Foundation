# MyML_Foundation 🤖

A structured collection of **machine learning notebooks** and **datasets** covering fundamental supervised and unsupervised learning algorithms.  
This repository is designed as a **beginner-to-intermediate ML learning resource**, with hands-on implementations, step-by-step explanations, and practical datasets.  

---

## 📂 Repository Structure

### 🗂 Datasets
- **Fertilizer Prediction.csv** – dataset for crop/fertilizer recommendations.  
- **StressLevelDataset.csv** – stress level prediction dataset.  
- **UniversalBank.csv** & **UniversalBank_Desc.txt** – customer data for predicting bank product adoption.  
- **delivery_time.csv** – dataset for regression tasks.  
- **drug200.csv** – drug classification dataset.  
- **spam.csv** – email spam/ham classification dataset.  

### 📘 Supervised Learning
- `Linear_Regression.ipynb` – predicting continuous outcomes using linear regression.  
- `Logistic_Regression.ipynb` – binary/multi-class classification with logistic regression.  
- `DecisionTree.ipynb` – classification and regression trees.  
- `RandomForest.ipynb` – ensemble learning using random forests.  
- `K_NearestNeighbours(KNN).ipynb` – instance-based learning with KNN.  
- `NaiveBayes.ipynb` – probabilistic classification with Naive Bayes.  
- `SupportVectorMachine(SVM).ipynb` – margin-based classification with SVMs.  

### 📗 Unsupervised Learning
- `Hierarchial_Clustering.ipynb` – hierarchical clustering for grouping data.  

### 📊 Additional
- `Pandas_basics.ipynb` – introduction to data preprocessing and analysis with Pandas.  

---

## 🚀 Features
- Covers **core supervised and unsupervised ML algorithms**.  
- Includes **real-world datasets** for practical experimentation.  
- Each notebook demonstrates **model building, training, and evaluation**.  
- Beginner-friendly with **step-by-step explanations**.
